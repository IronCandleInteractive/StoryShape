# StoryShape Downloads

StoryShape is a free, independently developed writing application built for writers, by a writer.

- **macOS:** free, signed Apple-silicon beta — [download the latest Mac release](https://storyshape.app/download/mac)
- **Windows:** free, unsigned x64 and ARM64 development previews — [choose a download](https://storyshape.app/download/)
- **Linux:** free, unsigned x64 development preview — [choose a download](https://storyshape.app/download/)
- **iPadOS:** in development, planned at $4.99 one time; not available for purchase

The desktop application is designed for offline work. Ordinary writing does not require an account, subscriptions, advertisements, or paid feature unlocks. Writers retain ownership of their manuscripts, notes, and worldbuilding materials.

Windows and Linux previews are portable archives. They are still being brought to Mac feature and design parity, and live platform acceptance testing is ongoing. Keep an independent backup and try them with a copy of an important project. Preview assets and checksums are attached to the [desktop prerelease](https://github.com/IronCandleInteractive/StoryShape/releases/tag/desktop-preview-v0.0.1); the separate Mac latest release and Sparkle feed are unchanged.

This public repository contains release distribution files and the Sparkle update feed only. It does not contain application source code. The current native Mac source is privately maintained by Iron Candle Interactive. Windows/Linux preview archives include Apache License 2.0 and notice files, but their source repository is not yet public. Source versions previously published under Apache License 2.0 retain their original licensing rights; see the [development-model update](https://storyshape.app/updates/development-model/) for current details.

For bug reports, feature requests, or general feedback, use the [StoryShape-Feedback forms](https://github.com/IronCandleInteractive/StoryShape-Feedback/issues/new/choose). For product support, visit [StoryShape Support](https://storyshape.app/support/).
