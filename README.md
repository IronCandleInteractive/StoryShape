# StoryShape Downloads

StoryShape is a free, independently developed writing application built for writers, by a writer.

- **macOS:** free Apple-silicon beta — [download the latest public release](https://github.com/IronCandleInteractive/StoryShape/releases/latest)
- **Windows:** free, planned
- **Linux:** free, planned
- **iPadOS:** in development, planned at $4.99 one time; not available for purchase

The desktop application is designed for offline work. Ordinary writing does not require an account, subscriptions, advertisements, or paid feature unlocks. Writers retain ownership of their manuscripts, notes, and worldbuilding materials.

This public repository contains release distribution files and the Sparkle update feed only. It does not contain application source code. Future first-party application source is privately maintained by Iron Candle Interactive. Source versions previously published under Apache License 2.0 retain their original licensing rights; see [StoryShape-Feedback](https://github.com/IronCandleInteractive/StoryShape-Feedback) for the current development model and availability.

For bug reports, feature requests, or general feedback, use the [StoryShape-Feedback forms](https://github.com/IronCandleInteractive/StoryShape-Feedback/issues/new/choose). For product support, visit [StoryShape Support](https://storyshape.app/support/).
